# Suha Notlar — Windows programı

Notlar Gmail hesabında saklandığı için bu program (Mail gibi) web adresini yükler
ve program kapısını `suhaDesktop` işaretiyle geçer. Tarayıcıda açılmaz.

- Adres: https://projectsuha.github.io/mail/notlar.html
- Derleme: GitHub Actions (windows-latest) → Release `notlar-son`.
